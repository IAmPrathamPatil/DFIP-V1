## Canonical ratio rule

Every ratio aggregates first, then divides:

```text
CTR  = SUM(unique_clicks) / SUM(delivered)
ROAS = SUM(revenue_inr) / SUM(total_cost)
```

SQL equivalent of DAX `DIVIDE(SUM(num), SUM(den))`:

```sql
SUM(num)::numeric / NULLIF(SUM(den), 0)
```

Zero or missing denominators are SQL NULL / DAX BLANK, never 0. Daily ratios
are never averaged. `SUM` skips NULL numerators; if every value is NULL the
SUM is NULL.
